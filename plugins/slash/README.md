# Slash for Cursor

Connects Cursor to your [Slash](https://slash.com) account through the official Slash MCP server (`https://api.slash.com/mcp/v2`).

## What you can do

- Check balances and accounts
- Search and summarize transactions
- Create and manage invoices, bills, contacts and recipients
- Move money between accounts and to recipients (always confirmed with you first)

## Setup

Install from the Cursor Marketplace, then sign in with your Slash account when prompted. Sign-in uses OAuth - no API keys to copy.
